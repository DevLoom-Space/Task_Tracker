# 📝 Task Tracker – Django Web Application

A secure and user-focused task management system built with **Django**.  
This project allows users to manage tasks efficiently with authentication, dashboard analytics, filtering, archiving, and a clean modern interface.

---

## 🚀 Live Features

### 🔐 Authentication
- User registration
- Login & logout
- Secure per-user task isolation
- Password visibility toggle (UX improvement)

### 📊 Dashboard
- Live task statistics
- Active task count
- Completed tasks
- Overdue tasks
- To Do / In Progress / Blocked breakdown
- Archived tasks count
- “Due Soon” preview (Next 7 Days)
- Clickable dashboard cards for filtered navigation

### 📝 Task Management
- Create tasks
- Update tasks
- View task details
- Toggle task status (Done / Not Done)
- Search functionality
- Filter by status
- Overdue filtering
- Pagination support

### 🗃 Archive Workflow
- Soft delete (Archive instead of immediate removal)
- Restore archived tasks
- Permanent delete (from archived view only)
- Safe confirmation before deletion

---

## 🛠 Tech Stack

- Python 3
- Django
- SQLite (Development)
- HTML5
- CSS3
- Class-Based Views (CBVs)
