📌 Task Tracker – Django

A modern, secure, and user-focused task management system built with Django.

This project allows users to manage tasks efficiently with a clean dashboard, filtering system, archive workflow, and authentication.

🚀 Features
🔐 Authentication

User registration (custom styled)

Login / Logout

Per-user task isolation (secure ownership filtering)

📊 Dashboard

Live task statistics

Active task count

Completed tasks

Overdue tasks

To Do / In Progress / Blocked breakdown

Due Soon (Next 7 Days) preview

Clickable dashboard cards for filtered views

📝 Task Management

Create tasks

Update tasks

View task details

Toggle Done / Not Done

Search tasks

Filter by status

Overdue filtering

Pagination

🗃 Archive Workflow

Soft delete (Archive)

Restore archived tasks

Permanent delete (from archive only)

Safe confirmation before deletion

🎨 UI / UX Improvements

Clean dashboard layout

Styled login & signup pages

Password visibility toggle

Smooth input styling

Status badges

Responsive layout

🛠 Tech Stack

Python 3

Django

SQLite (default development database)

HTML5

CSS3

Class-Based Views (CBVs)
